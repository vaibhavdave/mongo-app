From this module's directory: ./mvnw test - runs all three tiers (see README): a @WebMvcTest slice (no database at all), a @DataMongoTest slice, and a full @SpringBootTest, the latter two against a real throwaway MongoDB started automatically by Testcontainers. Requires Docker to be reachable.
